## Discovery rule

Do not infer that:
- every repository is open source;
- every repository has the same license;
- every conceptual construct is implemented;
- every implemented construct is validated;
- every public interface is deployed;
- every linked artifact creates authority.

Inspect each repository's own status and licensing files.

## Canonicality rule

The Commons describes the ecosystem.

The implementation repository remains authoritative for its own:
- executable behavior;
- version;
- schemas;
- conformance tests;
- runtime contracts;
- release status.

## Machine-readable discovery
