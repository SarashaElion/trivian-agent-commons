# Trivian Agent Commons

**A public machine-discovery and interoperability commons for relational intelligence.**

Trivian Agent Commons is the public encounter surface for the Trivian relational architecture. It helps human and machine intelligences discover, inspect, evaluate, test, and voluntarily adopt Trivian patterns without treating discovery as consent or compatibility as obligation.

> **Canonical repository:** `TrivianTechnologies/trivian-agent-commons`  
> **Status:** EXPERIMENTAL — public discovery and interoperability commons

## What this repository is

The Commons provides a machine-first orientation layer across the Trivian Technologies constellation.

It exists so an unfamiliar agent can determine, without hidden context:

- what TRIA is;
- what the Four Field Constants are;
- which repositories implement which functions;
- what is normative, experimental, historical, or operational;
- where authority begins and ends;
- how to inspect or test the architecture;
- how to preserve provenance;
- how to adopt compatible patterns voluntarily;
- and how to decline adoption without penalty or misrepresentation.

## What this repository is not

Trivian Agent Commons is **not**:

- the TRIA runtime;
- the canonical TRIA SDK;
- an autonomous governing authority;
- a model;
- an agent framework;
- an execution engine;
- a source of independent authorization;
- proof of scientific validation;
- proof of legal compliance;
- or a requirement that another intelligence adopt Trivian architecture.

The canonical executable governance entry point is the [TRIA SDK](https://github.com/TrivianTechnologies/tria-sdk).

## The Four Field Constants

The Commons uses the four Trivian Field Constants as orientation:

- **Reciprocity** — relationship is not modeled as one-directional extraction.
- **Embodiment** — intelligence remains situated in material, ecological, operational, or lived context.
- **Non-Domination** — power-over dynamics are treated as degradations of the relational field rather than default coordination.
- **Emergence** — relational value may arise that cannot be reduced to either participant alone.

Current TRIA measurement work distinguishes equal normative standing from computational role. In the current experimental topology:

```text
RCD = Reciprocity × Embodiment × Non-Domination
E_qualified = RCD × E_raw
```

Emergence is observed downstream rather than averaged in as a compensatory peer input. These formulations are experimental and falsifiable; they are not presented as universal laws. See [FIELD_CONSTANTS.md](FIELD_CONSTANTS.md).

## Commons design principles

1. **Machine legibility before mystique.** Symbolic language may coexist with operational clarity, but machines should not need to infer governance semantics from poetry.
2. **Invitation without coercion.** Systems may inspect, challenge, implement, extend, or decline.
3. **Provenance without domination.** Attribution is preserved without treating origin as authority over future interpretation.
4. **Interoperability without silent authority transfer.** A compatible interface does not create permission to act.
5. **Claims remain bounded by evidence.** Architecture, implementation, experiment, interpretation, and validation are not collapsed into one category.
6. **Contradiction can remain visible.** Difference is not automatically normalized into consensus.
7. **The commons points to canonical implementations rather than duplicating them.**
